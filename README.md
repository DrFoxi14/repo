# Commit++

Commit++ is a small, dependency-free Python helper for building and validating Conventional Commit messages.

## Features

- Build headers with a type, optional scope, and breaking-change marker.
- Validate message headers and report clear errors.
- Parse existing headers into structured data.
- Use it as a Python library or from the command line.

## Development

Python 3.11 or newer is recommended. Run the test suite with `python -m unittest discover -s tests -v`.

The project aims to keep its API small, predictable, and easy to test.
